E-commerceUNIQUE

Shipping rates

A shop prices parcels by destination zone and weight band. The table must have exactly one row for every parcel: a gap would leave a parcel without a price, and an overlap would make the price depend on the order of the rows.

The problem

Shipping rates, in words.

Six rows: three weight bands for domestic parcels, two for the EU, one for the rest of the world. Fixed prices are Decimals; the EU and world couriers charge by weight, so their price is an expression (F.weight_kg * 2.5 + 12) computed when the row is selected.

The unique hit policy selects the only row that matches and raises HitPolicyError if two do. The bands use between(2, 10, closed="right") so that a parcel of exactly 2 kg falls in one band only.

input.json
{"zone": "eu", "weight_kg": 3.4, "order_total": 64.0}

A 3.4 kg parcel to the EU, in an order of 64.00. The input in the JSON format, where decimals and dates have their own encoding; in Python it is the dict in the program below.

The rules in every language

One rule set, ten ways to write it.

Python and Rust run today, and the JSON tab is the rule set document the core writes. The other tabs are design previews of the planned bindings: they show the intended API, and the result they would print is the one the core computes for the same rules and data.

shipping.rsRust core · runs
//! Shipping rates: a decision table under the UNIQUE hit policy.
use cleanrules::ast::Closed;
use cleanrules::build::{Build, constant, field};
use cleanrules::format::{ValueContext, read_value, write_value};
use cleanrules::json::{Limits, parse, to_string};
use cleanrules::rules::{Config, HitPolicy, Rule, RuleSet};
use cleanrules::{Decimal, Value};

type Result<T> = std::result::Result<T, Box<dyn std::error::Error>>;

fn rule(name: &str, when: Build, then: Vec<(&str, Build)>) -> Result<Rule> {
    let then = then
        .into_iter()
        .map(|(key, value)| Ok((key.to_owned(), value.build()?)))
        .collect::<Result<Vec<_>>>()?;
    Ok(Rule::with_payload(name, when.build()?, then)?)
}

fn input(json: &str) -> Result<Value> {
    Ok(read_value(
        &parse(json, &Limits::default())?,
        "",
        ValueContext::Data,
    )?)
}

fn rates() -> Result<RuleSet> {
    let zone = |name: &str| field("zone").eq(name);
    let weight = || field("weight_kg");
    let price =
        |carrier: &str, price: Build| vec![("carrier", constant(carrier)), ("price", price)];
    let fixed = |text: &str| -> Result<Build> { Ok(constant(Decimal::parse(text)?)) };
    let table = vec![
        rule(
            "dom_small",
            zone("domestic") & weight().le(2),
            price("post", fixed("4.90")?),
        )?,
        rule(
            "dom_medium",
            zone("domestic") & weight().between_closed(2, 10, Closed::Right),
            price("post", fixed("8.90")?),
        )?,
        rule(
            "dom_large",
            zone("domestic") & weight().gt(10),
            price("courier", fixed("14.90")?),
        )?,
        rule(
            "eu_small",
            zone("eu") & weight().le(2),
            price("post", fixed("9.50")?),
        )?,
        rule(
            "eu_large",
            zone("eu") & weight().gt(2),
            price("courier", weight() * 2.5 + 12),
        )?,
        rule("world", zone("world"), price("courier", weight() * 6 + 25))?,
    ];
    let config = Config {
        hit_policy: HitPolicy::Unique,
        ..Config::default()
    };
    Ok(RuleSet::new(table, config)?)
}

fn main() -> Result<()> {
    let rates = rates()?;
    let parcel = input(r#"{"zone": "eu", "weight_kg": 3.4, "order_total": 64.0}"#)?;
    let decision = rates.evaluate(&parcel)?;
    let selected: Vec<&str> = decision.selected().map(|r| r.rule.name()).collect();
    println!("selected: {selected:?}");
    if let Some(output) = decision.output()? {
        println!("output:   {}", to_string(&write_value(&output)));
    }

    let lost = rates.evaluate(&input(r#"{"zone": "moon", "weight_kg": 1}"#)?)?;
    println!("moon:     {:?}", lost.output()?);
    Ok(())
}

output:   {"carrier":"courier","price":20.5}
moon:     None

// Design preview: the Java binding does not exist yet (phase G).
import io.github.cleanrules.*;
import java.math.BigDecimal;
import java.util.Map;

import static io.github.cleanrules.Conditions.*;

public class Shipping {
    public static void main(String[] args) {
        var domestic = field("zone").eq("domestic");
        var eu = field("zone").eq("eu");
        var weight = field("weight_kg");

        var rates = RuleSet.builder()
            .hitPolicy(HitPolicy.UNIQUE)
            .add(Rule.named("dom_small").when(domestic.and(weight.le(2)))
                .then("carrier", "post").then("price", new BigDecimal("4.90")))
            .add(Rule.named("dom_medium").when(domestic.and(weight.between(2, 10, Closed.RIGHT)))
                .then("carrier", "post").then("price", new BigDecimal("8.90")))
            .add(Rule.named("dom_large").when(domestic.and(weight.gt(10)))
                .then("carrier", "courier").then("price", new BigDecimal("14.90")))
            .add(Rule.named("eu_small").when(eu.and(weight.le(2)))
                .then("carrier", "post").then("price", new BigDecimal("9.50")))
            .add(Rule.named("eu_large").when(eu.and(weight.gt(2)))
                .then("carrier", "courier").then("price", weight.times(2.5).plus(12)))
            .add(Rule.named("world").when(field("zone").eq("world"))
                .then("carrier", "courier").then("price", weight.times(6).plus(25)))
            .build();

        var decision = rates.evaluate(Map.of("zone", "eu", "weight_kg", 3.4, "order_total", 64.0));
        System.out.println(decision.fired());
        System.out.println(decision.output().orElseThrow());
    }
}

// Design preview: the Go binding does not exist yet (phase H).
package main

import (
	"fmt"
	"log"

	cr "github.com/cleanrules/cleanrules/bindings/go"
)

func main() {
	zone, weight := cr.Field("zone"), cr.Field("weight_kg")
	domestic, eu := zone.Eq("domestic"), zone.Eq("eu")
	rate := func(name string, when cr.Expr, carrier string, price any) *cr.Rule {
		return cr.NewRule(name, when).Then("carrier", carrier).Then("price", price)
	}
	rates, err := cr.NewRuleSet([]*cr.Rule{
		rate("dom_small", cr.And(domestic, weight.Le(2)), "post", cr.MustDecimal("4.90")),
		rate("dom_medium", cr.And(domestic, weight.BetweenClosed(2, 10, cr.Right)), "post", cr.MustDecimal("8.90")),
		rate("dom_large", cr.And(domestic, weight.Gt(10)), "courier", cr.MustDecimal("14.90")),
		rate("eu_small", cr.And(eu, weight.Le(2)), "post", cr.MustDecimal("9.50")),
		rate("eu_large", cr.And(eu, weight.Gt(2)), "courier", weight.Mul(2.5).Add(12)),
		rate("world", zone.Eq("world"), "courier", weight.Mul(6).Add(25)),
	}, cr.WithHitPolicy(cr.Unique))
	if err != nil {
		log.Fatal(err)
	}

	decision, err := rates.Evaluate(map[string]any{"zone": "eu", "weight_kg": 3.4, "order_total": 64.0})
	if err != nil {
		log.Fatal(err)
	}
	output, err := decision.Output()
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(decision.Fired())
	fmt.Println(output)
}

// Design preview: the C binding does not exist yet (phase E).
#include <stdio.h>
#include <cleanrules.h>

static int fail(cr_status status) {
    fprintf(stderr, "%s: %s\n", cr_status_name(status), cr_error_message(cr_last_error()));
    return 1;
}

int main(void) {
    cr_ruleset *rules = NULL;
    cr_decision *decision = NULL;
    char *output = NULL;

    /* The rule set document shown in the JSON tab. */
    cr_status status = cr_ruleset_read_file("shipping.ruleset.json", &rules);
    if (status != CR_OK) return fail(status);

    const char *parcel =
        "{\"zone\": \"eu\", \"weight_kg\": 3.4, \"order_total\": 64.0}";
    status = cr_ruleset_evaluate_json(rules, parcel, &decision);
    if (status == CR_OK) status = cr_decision_output_json(decision, &output);
    if (status == CR_OK) puts(output);  /* a JSON object, or null */
    else fail(status);

    cr_string_free(output);
    cr_decision_free(decision);
    cr_ruleset_free(rules);
    return status == CR_OK ? 0 : 1;
}

namespace cr = cleanrules;
using cr::F;

int main() {

    auto eu = F("zone") == "eu";

        return cr::Value{{"carrier", carrier}, {"price", price}};
    };

        cr::Rule("dom_medium", domestic & weight.between(2, 10, cr::Closed::right))

What happens if…

Change the input, see the outcome move.

Marketing adds a rule. "Free shipping on orders of 100 or more" overlaps every row. Under unique, an order of 120 now raises HitPolicyError naming both rows, instead of silently picking one. That is the point of unique: overlaps surface as errors the first time they occur, with the rules involved.

If the promotion is meant to override the table, say so: put it first under first (as below), or give it a higher priority under priority.

Python · continues the programPython binding · runs
from cleanrules import HitPolicyError

promo = Rule("free_shipping", F.order_total >= 100, {"carrier": "post", "price": 0})
try:
    RuleSet([*table, promo], hit_policy="unique").evaluate({**parcel, "order_total": 120})
except HitPolicyError as err:
    print(err.code, err.rules)
    print(err)

first = RuleSet([promo, *table], hit_policy="first")
print(dict(first.evaluate({**parcel, "order_total": 120}).output))
Output
hit_policy_error ('eu_large', 'free_shipping')
2 rules fired under the unique hit policy
hint: make the conditions mutually exclusive, or use first or priority
