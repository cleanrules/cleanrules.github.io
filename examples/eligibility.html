Eligibility with dates

A housing grant has four requirements: two years of residence, being an adult, a household income under 28,000, and an application submitted before the deadline, 15 December 2026 at 14:00 in Madrid.

The problem

Eligibility with dates, in words.

One rule whose condition is the conjunction of the four requirements. The dates are date constants; the deadline is an aware datetime with the Europe/Madrid zone, so it means the same instant wherever the code runs. The grant is a Decimal.

input.json
{
  "residence_since": {"$date": "2025-01-20"},
  "birth_date": {"$date": "1999-04-02"},
  "household_income": 26500,
  "submitted_at": {"$datetime": "2026-12-16T09:30:00+01:00[Europe/Madrid]"}
}

An applicant resident since 20 January 2025, born in 1999, with a household income of 26,500, who applied on 16 December 2026 at 09:30 Madrid time. The input in the JSON format, where decimals and dates have their own encoding; in Python it is the dict in the program below.

The rules in every language

One rule set, ten ways to write it.

Python and Rust run today, and the JSON tab is the rule set document the core writes. The other tabs are design previews of the planned bindings: they show the intended API, and the result they would print is the one the core computes for the same rules and data.

eligibility.rsRust core · runs
//! Eligibility with dates: counterfactuals in days and in microseconds.
use cleanrules::Value;
use cleanrules::build::{Build, constant, field};
use cleanrules::explain::{Cause, Gap, Requirement, explain};
use cleanrules::format::{ValueContext, read_value, write_path, write_value};
use cleanrules::jiff::civil::date;
use cleanrules::json::{Limits, parse, to_string};
use cleanrules::rules::{Config, Rule, RuleSet};

type Result<T> = std::result::Result<T, Box<dyn std::error::Error>>;

fn rule(name: &str, when: Build, then: Vec<(&str, Build)>) -> Result<Rule> {
    let then = then
        .into_iter()
        .map(|(key, value)| Ok((key.to_owned(), value.build()?)))
        .collect::<Result<Vec<_>>>()?;
    Ok(Rule::with_payload(name, when.build()?, then)?)
}

fn input(json: &str) -> Result<Value> {
    Ok(read_value(
        &parse(json, &Limits::default())?,
        "",
        ValueContext::Data,
    )?)
}

fn causes<'r, 'd, 'a>(requirement: &'r Requirement<'d, 'a>) -> Vec<&'r Cause<'d, 'a>> {
    match requirement {
        Requirement::Cause(cause) => vec![cause],
        Requirement::Group(_, items) => items.iter().flat_map(|item| causes(item)).collect(),
    }
}

fn rules() -> Result<RuleSet> {
    // An aware datetime constant is read from the JSON format, which keeps the zone.
    let deadline = input(r#"{"$datetime": "2026-12-15T14:00:00+01:00[Europe/Madrid]"}"#)?;
    let grant = rule(
        "housing_grant",
        field("residence_since").le(date(2024, 11, 1))
            & field("birth_date").le(date(2008, 11, 1))
            & field("household_income").lt(28_000)
            & field("submitted_at").le(deadline),
        vec![("grant", constant(cleanrules::Decimal::parse("1500.00")?))],
    )?
    .description("Two years of residence, adult, low income, before the deadline");
    Ok(RuleSet::new(vec![grant], Config::default())?)
}

fn main() -> Result<()> {
    let rules = rules()?;
    let applicant = input(
        r#"{"residence_since": {"$date": "2025-01-20"}, "birth_date": {"$date": "1999-04-02"},
            "household_income": 26500,
            "submitted_at": {"$datetime": "2026-12-16T09:30:00+01:00[Europe/Madrid]"}}"#,
    )?;
    let decision = rules.evaluate(&applicant)?;
    let explanation = explain(&decision);
    let grant = &explanation.rules[0];
    println!(
        "{}: {} (achievable: {:?})",
        grant.rule,
        grant.status.as_str(),
        grant.achievable
    );
    for cause in causes(&grant.requirement)
        .into_iter()
        .filter(|c| !c.holds())
    {
        let Some(cf) = &cause.counterfactual else {
            continue;
        };
        let gap = match &cf.gap {
            Some(Gap::Days(days)) => format!("{days} days"),
            Some(Gap::Microseconds(us)) => format!("{} hours", *us as f64 / 3.6e9),
            Some(Gap::Number(n)) => to_string(&write_value(n)),
            None => "none".to_owned(),
        };
        println!(
            "  needs {} {} {}: gap {gap}",
            to_string(&write_path(&cf.path)),
            cf.op.tag(),
            to_string(&write_value(&cf.target))
        );
    }
    Ok(())
}

import io.github.cleanrules.*;
import java.math.BigDecimal;
import java.time.LocalDate;
import java.time.ZoneId;
import java.time.ZonedDateTime;

import static io.github.cleanrules.Conditions.*;

public class Eligibility {
    record Applicant(LocalDate residence_since, LocalDate birth_date, int household_income,
                     ZonedDateTime submitted_at) {}

    public static void main(String[] args) {
        var madrid = ZoneId.of("Europe/Madrid");
        var grant = Rule.named("housing_grant")
            .when(field("residence_since").le(LocalDate.of(2024, 11, 1))
                .and(field("birth_date").le(LocalDate.of(2008, 11, 1)))
                .and(field("household_income").lt(28_000))
                .and(field("submitted_at").le(ZonedDateTime.of(2026, 12, 15, 14, 0, 0, 0, madrid))))
            .then("grant", new BigDecimal("1500.00"))
            .description("Two years of residence, adult, low income, before the deadline");
        var rules = RuleSet.builder().add(grant).build();

        var applicant = new Applicant(
            LocalDate.of(2025, 1, 20),
            LocalDate.of(1999, 4, 2),
            26_500,
            ZonedDateTime.of(2026, 12, 16, 9, 30, 0, 0, madrid));
        var decision = rules.evaluate(applicant);
        System.out.println(decision.fired());
        System.out.println(decision.output());
    }
}

// Design preview: the Go binding does not exist yet (phase H).
package main

import (
	"fmt"
	"log"
	"time"

	cr "github.com/cleanrules/cleanrules/bindings/go"
)

type Applicant struct {
	ResidenceSince  cr.Date   `json:"residence_since"`
	BirthDate       cr.Date   `json:"birth_date"`
	HouseholdIncome int       `json:"household_income"`
	SubmittedAt     time.Time `json:"submitted_at"`
}

func main() {
	madrid, err := time.LoadLocation("Europe/Madrid")
	if err != nil {
		log.Fatal(err)
	}
	grant := cr.NewRule("housing_grant", cr.And(
		cr.Field("residence_since").Le(cr.NewDate(2024, time.November, 1)),
		cr.Field("birth_date").Le(cr.NewDate(2008, time.November, 1)),
		cr.Field("household_income").Lt(28000),
		cr.Field("submitted_at").Le(time.Date(2026, time.December, 15, 14, 0, 0, 0, madrid)),
	)).Then("grant", cr.MustDecimal("1500.00")).
		Description("Two years of residence, adult, low income, before the deadline")
	rules, err := cr.NewRuleSet([]*cr.Rule{grant})
	if err != nil {
		log.Fatal(err)
	}

	decision, err := rules.Evaluate(Applicant{
		ResidenceSince:  cr.NewDate(2025, time.January, 20),
		BirthDate:       cr.NewDate(1999, time.April, 2),
		HouseholdIncome: 26500,
		SubmittedAt:     time.Date(2026, time.December, 16, 9, 30, 0, 0, madrid),
	})
	if err != nil {
		log.Fatal(err)
	}
	output, err := decision.Output()
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(decision.Fired())
	fmt.Println(output)
}

// Design preview: the C binding does not exist yet (phase E).
#include <stdio.h>
#include <cleanrules.h>

static int fail(cr_status status) {
    fprintf(stderr, "%s: %s\n", cr_status_name(status), cr_error_message(cr_last_error()));
    return 1;
}

int main(void) {
    cr_ruleset *rules = NULL;
    cr_decision *decision = NULL;
    char *output = NULL;

    /* The rule set document shown in the JSON tab. */
    cr_status status = cr_ruleset_read_file("eligibility.ruleset.json", &rules);
    if (status != CR_OK) return fail(status);

    const char *applicant =
        "{\"residence_since\": {\"$date\": \"2025-01-20\"}, "
        "\"birth_date\": {\"$date\": \"1999-04-02\"}, \"household_income\": 26500, "
        "\"submitted_at\": {\"$datetime\": \"2026-12-16T09:30:00+01:00[Europe/Madrid]\"}}";
    status = cr_ruleset_evaluate_json(rules, applicant, &decision);
    if (status == CR_OK) status = cr_decision_output_json(decision, &output);
    if (status == CR_OK) puts(output);  /* a JSON object, or null */
    else fail(status);

    cr_string_free(output);
    cr_decision_free(decision);
    cr_ruleset_free(rules);
    return status == CR_OK ? 0 : 1;
}

The explanation

Why, and why not.

Two requirements failed, each with a counterfactual. Residence needed to start 80 days earlier (a gap in whole days, since both are dates). The application was 19.5 hours late (70,200 seconds): both are aware datetimes, so the gap is between instants. Age and income held, so they are not listed. achievable is True: fixing these two would be enough.

What happens if…

Change the input, see the outcome move.

An eligible applicant gets the grant as a Decimal. An application without a timestamp is not rejected for lateness: the rule is unknown, with a missing_field reason, which a case worker can follow up.
