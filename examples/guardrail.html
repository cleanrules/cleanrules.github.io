AI-agent tool-call guardrail

An AI agent can run shell commands, deploy and pay invoices. Before each tool call runs, a rule set decides: allow it, ask a human, or deny it. The decision must be deterministic and explainable, whatever the model was thinking.

The problem

AI-agent tool-call guardrail, in words.

  • deny_destructive_shell: a bash call whose command contains a recursive rm is denied (priority 100);
  • deny_outside_hours: deployments and payments outside 08:00 to 20:00 are denied (80);
  • ask_large_payment: a payment above 500.00 needs a human's approval (50);
  • allow: anything else is allowed (0).

The tool call is the input: the tool's name, its arguments and some context. priority makes deny beat ask beat allow. This is the shape of the planned guardrails (phase O); the rules themselves run today.

input.json
{
  "tool": {
    "name": "pay_invoice",
    "args": {"invoice": "F-2026-118", "amount": {"$decimal": "1250.00"}}
  },
  "context": {"hour": 14}
}

The agent wants to pay invoice F-2026-118 for 1,250.00 at 14:00. The input in the JSON format, where decimals and dates have their own encoding; in Python it is the dict in the program below.

from decimal import Decimal

from cleanrules import Const, F, Rule, RuleSet

guard = RuleSet(
    [
        Rule("deny_destructive_shell",
             (F.tool.name == "bash") & F.tool.args.command.matches(r"\brm\s+-[a-zA-Z]*r"),
             {"verdict": "deny"}, priority=100, tags=["safety"],
             description="Never let the agent delete recursively"),
        Rule("deny_outside_hours",
             F.tool.name.is_in(["deploy", "pay_invoice"])
             & ~F.context.hour.between(8, 20, closed="left"),

             {"verdict": "ask"}, priority=50, tags=["money"]),
        Rule("allow", Const(True), {"verdict": "allow"}),
    ],
    hit_policy="priority",
)

guardrail.rsRust core · runs
//! A guardrail for an AI agent's tool calls: allow, ask or deny.
use cleanrules::ast::Closed;
use cleanrules::build::{Build, constant, field};
use cleanrules::format::{ValueContext, read_value, write_value};
use cleanrules::json::{Limits, parse, to_string};
use cleanrules::rules::{Config, HitPolicy, Rule, RuleSet};
use cleanrules::{Decimal, Value};

type Result<T> = std::result::Result<T, Box<dyn std::error::Error>>;

fn rule(name: &str, when: Build, then: Vec<(&str, Build)>) -> Result<Rule> {
    let then = then
        .into_iter()
        .map(|(key, value)| Ok((key.to_owned(), value.build()?)))
        .collect::<Result<Vec<_>>>()?;
    Ok(Rule::with_payload(name, when.build()?, then)?)
}

fn input(json: &str) -> Result<Value> {
    Ok(read_value(
        &parse(json, &Limits::default())?,
        "",
        ValueContext::Data,
    )?)
}

fn guard() -> Result<RuleSet> {
    let tool = || field("tool").get("name");
    let args = || field("tool").get("args");
    let verdict = |v: &str| vec![("verdict", constant(v))];
    let rules = vec![
        rule(
            "deny_destructive_shell",
            tool().eq("bash") & args().get("command").matches(r"\brm\s+-[a-zA-Z]*r"),
            verdict("deny"),
        )?
        .priority(100)
        .tags(["safety"])
        .description("Never let the agent delete recursively"),
        rule(
            "deny_outside_hours",
            tool().is_in(["deploy", "pay_invoice"])
                & !field("context")
                    .get("hour")
                    .between_closed(8, 20, Closed::Left),
            verdict("deny"),
        )?
        .priority(80)
        .tags(["safety"]),
        rule(
            "ask_large_payment",
            tool().eq("pay_invoice") & args().get("amount").gt(Decimal::parse("500.00")?),
            verdict("ask"),
        )?
        .priority(50)
        .tags(["money"]),
        rule("allow", constant(true), verdict("allow"))?,
    ];
    let config = Config {
        hit_policy: HitPolicy::Priority,
        ..Config::default()
    };
    Ok(RuleSet::new(rules, config)?)
}

fn main() -> Result<()> {
    let guard = guard()?;
    let calls = [
        r#"{"tool": {"name": "pay_invoice", "args": {"invoice": "F-2026-118", "amount": {"$decimal": "1250.00"}}}, "context": {"hour": 14}}"#,
        r#"{"tool": {"name": "pay_invoice", "args": {"amount": {"$decimal": "120.00"}}}, "context": {"hour": 14}}"#,
        r#"{"tool": {"name": "bash", "args": {"command": "rm -rf ./build"}}, "context": {"hour": 23}}"#,
    ];
    for call in calls {
        let decision = guard.evaluate(&input(call)?)?;
        let winner = decision.selected().next().map_or("-", |r| r.rule.name());
        let output = decision
            .output()?
            .map(|v| to_string(&write_value(&v)))
            .unwrap_or_default();
        println!("{output:<20} by {winner}");
    }
    Ok(())
}

import io.github.cleanrules.*;
import java.math.BigDecimal;
import java.util.Map;

import static io.github.cleanrules.Conditions.*;

public class Guardrail {
    public static void main(String[] args) {
        var tool = field("tool", "name");
        var guard = RuleSet.builder()
            .hitPolicy(HitPolicy.PRIORITY)
            .add(Rule.named("deny_destructive_shell")
                .when(tool.eq("bash").and(field("tool", "args", "command").matches("\\brm\\s+-[a-zA-Z]*r")))
                .then("verdict", "deny").priority(100).tags("safety")
                .description("Never let the agent delete recursively"))
            .add(Rule.named("deny_outside_hours")
                .when(tool.isIn("deploy", "pay_invoice")
                    .and(field("context", "hour").between(8, 20, Closed.LEFT).not()))
                .then("verdict", "deny").priority(80).tags("safety"))
            .add(Rule.named("ask_large_payment")
                .when(tool.eq("pay_invoice").and(field("tool", "args", "amount").gt(new BigDecimal("500.00"))))
                .then("verdict", "ask").priority(50).tags("money"))
            .add(Rule.named("allow").when(constant(true)).then("verdict", "allow"))
            .build();

        var call = Map.of(
            "tool", Map.of("name", "pay_invoice",
                "args", Map.of("invoice", "F-2026-118", "amount", new BigDecimal("1250.00"))),
            "context", Map.of("hour", 14));
        var decision = guard.evaluate(call);
        System.out.println(decision.fired());
        System.out.println(decision.output().orElseThrow());
    }
}

package main

import (
	"fmt"
	"log"

	cr "github.com/cleanrules/cleanrules/bindings/go"
)

func main() {
	tool := cr.Field("tool", "name")
	guard, err := cr.NewRuleSet([]*cr.Rule{
		cr.NewRule("deny_destructive_shell", cr.And(
			tool.Eq("bash"),
			cr.Field("tool", "args", "command").Matches(`\brm\s+-[a-zA-Z]*r`),
		)).Then("verdict", "deny").Priority(100).Tags("safety").
			Description("Never let the agent delete recursively"),

			tool.In("deploy", "pay_invoice"),
			cr.Not(cr.Field("context", "hour").BetweenClosed(8, 20, cr.Left)),
		)).Then("verdict", "deny").Priority(80).Tags("safety"),
		cr.NewRule("ask_large_payment", cr.And(
			tool.Eq("pay_invoice"),
			cr.Field("tool", "args", "amount").Gt(cr.MustDecimal("500.00")),
		)).Then("verdict", "ask").Priority(50).Tags("money"),
		cr.NewRule("allow", cr.Const(true)).Then("verdict", "allow"),
	}, cr.WithHitPolicy(cr.Priority))
	if err != nil {
		log.Fatal(err)
	}

		},
		"context": map[string]any{"hour": 14},
	})
	if err != nil {
		log.Fatal(err)
	}
	output, err := decision.Output()
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(decision.Fired())
	fmt.Println(output)
}

// Design preview: the C binding does not exist yet (phase E).
#include <stdio.h>
#include <cleanrules.h>

static int fail(cr_status status) {
    fprintf(stderr, "%s: %s\n", cr_status_name(status), cr_error_message(cr_last_error()));
    return 1;
}

int main(void) {
    cr_ruleset *rules = NULL;
    cr_decision *decision = NULL;
    char *output = NULL;

    /* The rule set document shown in the JSON tab. */
    cr_status status = cr_ruleset_read_file("guardrail.ruleset.json", &rules);
    if (status != CR_OK) return fail(status);

    const char *call =
        "{\"tool\": {\"name\": \"pay_invoice\", "
        "\"args\": {\"invoice\": \"F-2026-118\", \"amount\": {\"$decimal\": \"1250.00\"}}}, "
        "\"context\": {\"hour\": 14}}";
    status = cr_ruleset_evaluate_json(rules, call, &decision);
    if (status == CR_OK) status = cr_decision_output_json(decision, &output);
    if (status == CR_OK) puts(output);  /* a JSON object, or null */
    else fail(status);

    cr_string_free(output);
    cr_decision_free(decision);
    cr_ruleset_free(rules);
    return status == CR_OK ? 0 : 1;
}

The explanation

Why, and why not.

The explanation is what the human sees: which rule asked, and that no deny rule applied. Amounts are Decimals, compared exactly.

What happens if…

Change the input, see the outcome move.

Three more calls. A small payment is allowed. rm -rf ./build is denied, and so is a payment at 21:00, even though it is small: the deny rule outranks allow, which fired for every call.

What the guardrail reads. The summary lists every field the rules read, which is what an agent framework must provide with each call; the planned MCP server will derive its input schema from it. Tags group the rules for review.
