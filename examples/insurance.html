Insurance premium

A car insurer prices a policy as a base premium plus surcharges and discounts. Every rule that applies contributes an amount, and the premium is their sum. One contribution is computed from the data: a surcharge proportional to the car's value.

The problem

Insurance premium, in words.

  • base: every adult driver pays 420;
  • young_driver (under 25): +380; senior_driver (75 or more): +150;
  • recent_claims (2 or more in three years): +260;
  • city_zone (urban or metro): +90;
  • no_claims_bonus (no claims and at least 5 years licensed): −110;
  • high_value_car (worth more than 40,000): 0.4 % of the car's value.

The collect hit policy selects every rule that fired, in rule order, and the sum aggregate adds their payloads key by key. Each rule stays small and independent, and the explanation shows every contribution.

input.json
{
  "age": 31,
  "claims_3y": 0,
  "years_licensed": 9,
  "zone": "urban",
  "car_value": 52000
}

A 31-year-old driver, licensed for 9 years, no claims, living in an urban zone, with a car worth 52,000. The input in the JSON format, where decimals and dates have their own encoding; in Python it is the dict in the program below.

The rules in every language

One rule set, ten ways to write it.

Python and Rust run today, and the JSON tab is the rule set document the core writes. The other tabs are design previews of the planned bindings: they show the intended API, and the result they would print is the one the core computes for the same rules and data.

insurance.rsRust core · runs
//! Insurance premium: COLLECT with the sum aggregate.
use cleanrules::Value;
use cleanrules::build::{Build, constant, field};
use cleanrules::format::{ValueContext, read_value, write_value};
use cleanrules::json::{Limits, parse, to_string};
use cleanrules::rules::{Aggregate, Config, HitPolicy, Rule, RuleSet};

type Result<T> = std::result::Result<T, Box<dyn std::error::Error>>;

fn rule(name: &str, when: Build, then: Vec<(&str, Build)>) -> Result<Rule> {
    let then = then
        .into_iter()
        .map(|(key, value)| Ok((key.to_owned(), value.build()?)))
        .collect::<Result<Vec<_>>>()?;
    Ok(Rule::with_payload(name, when.build()?, then)?)
}

fn input(json: &str) -> Result<Value> {
    Ok(read_value(
        &parse(json, &Limits::default())?,
        "",
        ValueContext::Data,
    )?)
}

fn rules() -> Result<RuleSet> {
    let premium = |amount: Build| vec![("premium", amount)];
    let rules = vec![
        rule("base", field("age").ge(18), premium(constant(420)))?,
        rule("young_driver", field("age").lt(25), premium(constant(380)))?,
        rule("senior_driver", field("age").ge(75), premium(constant(150)))?,
        rule(
            "recent_claims",
            field("claims_3y").ge(2),
            premium(constant(260)),
        )?,
        rule(
            "city_zone",
            field("zone").is_in(["urban", "metro"]),
            premium(constant(90)),
        )?,
        rule(
            "no_claims_bonus",
            field("claims_3y").eq(0) & field("years_licensed").ge(5),
            premium(constant(-110)),
        )?,
        rule(
            "high_value_car",
            field("car_value").gt(40_000),
            premium(field("car_value") * 0.004),
        )?,
    ];
    let config = Config {
        hit_policy: HitPolicy::Collect,
        aggregate: Some(Aggregate::Sum),
        ..Config::default()
    };
    Ok(RuleSet::new(rules, config)?)
}

fn main() -> Result<()> {
    let rules = rules()?;
    let driver = input(
        r#"{"age": 31, "claims_3y": 0, "years_licensed": 9, "zone": "urban", "car_value": 52000}"#,
    )?;
    let decision = rules.evaluate(&driver)?;
    for result in decision.selected() {
        let output: Vec<String> = result
            .output()
            .iter()
            .map(|(key, value)| format!("{key}={}", to_string(&write_value(value))))
            .collect();
        println!("{:<16} {}", result.rule.name(), output.join(", "));
    }
    if let Some(total) = decision.output()? {
        println!("output: {}", to_string(&write_value(&total)));
    }
    Ok(())
}

// Design preview: the Java binding does not exist yet (phase G).
import io.github.cleanrules.*;

import static io.github.cleanrules.Conditions.*;

public class Insurance {
    record Driver(int age, int claims_3y, int years_licensed, String zone, int car_value) {}

    public static void main(String[] args) {
        var rules = RuleSet.builder()
            .hitPolicy(HitPolicy.COLLECT)
            .aggregate(Aggregate.SUM)
            .add(Rule.named("base").when(field("age").ge(18)).then("premium", 420))
            .add(Rule.named("young_driver").when(field("age").lt(25)).then("premium", 380))
            .add(Rule.named("senior_driver").when(field("age").ge(75)).then("premium", 150))
            .add(Rule.named("recent_claims").when(field("claims_3y").ge(2)).then("premium", 260))
            .add(Rule.named("city_zone").when(field("zone").isIn("urban", "metro")).then("premium", 90))
            .add(Rule.named("no_claims_bonus")
                .when(field("claims_3y").eq(0).and(field("years_licensed").ge(5)))
                .then("premium", -110))
            .add(Rule.named("high_value_car").when(field("car_value").gt(40_000))
                .then("premium", field("car_value").times(0.004)))
            .build();

        var decision = rules.evaluate(new Driver(31, 0, 9, "urban", 52_000));
        System.out.println(decision.fired());
        System.out.println(decision.output().orElseThrow());
    }
}

// Design preview: the Go binding does not exist yet (phase H).
package main

import (
	"fmt"
	"log"

	cr "github.com/cleanrules/cleanrules/bindings/go"
)

type Driver struct {
	Age           int    `json:"age"`
	Claims3y      int    `json:"claims_3y"`
	YearsLicensed int    `json:"years_licensed"`
	Zone          string `json:"zone"`
	CarValue      int    `json:"car_value"`
}

func main() {
	premium := func(name string, when cr.Expr, amount any) *cr.Rule {
		return cr.NewRule(name, when).Then("premium", amount)
	}
	rules, err := cr.NewRuleSet([]*cr.Rule{
		premium("base", cr.Field("age").Ge(18), 420),
		premium("young_driver", cr.Field("age").Lt(25), 380),
		premium("senior_driver", cr.Field("age").Ge(75), 150),
		premium("recent_claims", cr.Field("claims_3y").Ge(2), 260),
		premium("city_zone", cr.Field("zone").In("urban", "metro"), 90),
		premium("no_claims_bonus",
			cr.And(cr.Field("claims_3y").Eq(0), cr.Field("years_licensed").Ge(5)), -110),
		premium("high_value_car", cr.Field("car_value").Gt(40000), cr.Field("car_value").Mul(0.004)),
	}, cr.WithHitPolicy(cr.Collect), cr.WithAggregate(cr.Sum))
	if err != nil {
		log.Fatal(err)
	}

	decision, err := rules.Evaluate(Driver{Age: 31, Claims3y: 0, YearsLicensed: 9, Zone: "urban", CarValue: 52000})
	if err != nil {
		log.Fatal(err)
	}
	output, err := decision.Output()
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(decision.Fired())
	fmt.Println(output)
}

/* A whole file, or NULL. */
static char *read_file(const char *path, size_t *len) {
    FILE *file = fopen(path, "rb");
    char *text = NULL;
    if (file != NULL && fseek(file, 0, SEEK_END) == 0) {
        long size = ftell(file);
        if (size >= 0 && fseek(file, 0, SEEK_SET) == 0 && (text = malloc((size_t)size + 1)) != NULL) {
            *len = fread(text, 1, (size_t)size, file);
        }
    }
    if (file != NULL) fclose(file);
    return text;
}

static int fail(cr_error *error) {
    fprintf(stderr, "%s: %s\n", cr_status_name(cr_error_code(error)), cr_error_message(error));
    cr_error_free(error);
    return 1;
}

int main(void) {
    /* The rule set document shown in the JSON tab. */
    size_t len = 0;
    char *text = read_file("insurance.ruleset.json", &len);
    if (text == NULL) {
        perror("insurance.ruleset.json");
        return 1;
    }
    cr_error *error = NULL;
    cr_ruleset *rules = NULL;
    cr_status status = cr_ruleset_read(text, len, CR_FORMAT_JSON, NULL, &rules, &error);
    free(text);
    if (status != CR_OK) return fail(error);

    const char *driver =
        "{\"age\": 31, \"claims_3y\": 0, \"years_licensed\": 9, "
        "\"zone\": \"urban\", \"car_value\": 52000}";
    cr_decision *decision = NULL;
    char *output = NULL;
    if (cr_ruleset_evaluate(rules, driver, strlen(driver), NULL, &decision, &error) == CR_OK &&
        cr_decision_output(decision, &output, NULL, &error) == CR_OK) {
        puts(output);  /* a JSON object, or null */
    }
    cr_string_free(output);
    cr_decision_free(decision);
    cr_ruleset_free(rules);
    return error == NULL ? 0 : fail(error);
}

The decision document records every rule's result tree, with each value read; its outputs are derived from it. It equals decision.to_dict() in Python.

The explanation

Why, and why not.

decision.selected holds every rule that fired, each with its own evaluated payload, so the premium can be itemised for the customer or for an auditor. The rules that did not fire are listed with their truth values.

What happens if…

Change the input, see the outcome move.

The claims history is missing. recent_claims and no_claims_bonus both read claims_3y, so both are unknown and neither fires. The surcharge is not applied, but neither is the bonus: the premium goes up to 718.0. Missing data is never treated as "no claims".

If a missing history should be an error rather than a higher quote, build the same rules with strict=True: evaluation raises MissingFieldError, naming the first rule that read the field and the field's path.
