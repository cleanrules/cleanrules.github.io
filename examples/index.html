Worked examples

Eight problems, solved and explained.

Each example states a problem, writes its rules in ten languages, and shows the real decision and explanation for one input, then what changes when the input does. Python and Rust run; the JSON is written by the core; the other languages are design previews.

01

Loan approval

Decline, refer or approve an applicant, with hard stops that override everything, and tell a near miss exactly how far it was.

 02

Insurance premium

Add up a base premium, surcharges and discounts; see each rule's contribution; and make sure missing claims history never earns a discount.

 03

Shipping rates

A decision table of zones and weight bands where exactly one row must match, and what happens when a new rule overlaps it.

Fraud flags

Raise every flag that applies to a card transaction, each with risk points, then total them with the same rules under COLLECT.

How these pages are made

Nothing is typed by hand that a program could print.

  • The Python code is run with the binding built from source, cell by cell in one session per page, and the output is pasted as printed.
  • The Rust programs are compiled against the core crate and run; their output is pasted as printed.
  • The JSON rule set is written by the core from the Python rules. The build checks that the Rust program's rule set writes the identical document, and that Python's decision, explanation and summary documents equal the core's for the same input.
  • TypeScript, Java, Scala, Go, C, C++ and Erlang are design previews: their bindings do not exist yet (phases E to N), so their code shows the intended API and does not run. The result they would print is the core's.

The concepts behind each example are taught in the manual.
