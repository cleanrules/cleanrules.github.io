Rust API

The main public items of the cleanrules crate, module by module, with their signatures and the first paragraph of their documentation comments. The listing is generated from the crate's source.

This is a guided subset: the items you use to build rules, evaluate, explain and read or write the JSON format. cargo doc --open -p cleanrules in a clone of the repository renders the complete documentation; the crate will be on docs.rs once it is published.

Operators on Build#

& (and), | (or) and ! (not) combine conditions; +, -, *, / and unary - build arithmetic, with a Build, a number or any value convertible into a constant on the right (and i64 or f64 on the left). Constants convert from bool, i32, i64, u32, f64, &str, String, Decimal, jiff::civil::Date, jiff::civil::DateTime and Value.

structDecimal

pub struct Decimal

An exact decimal: a coefficient c with |c| < 10^38 and a scale s from 0 to 38, whose value is c × 10^-s, or one of the two infinities.

Methods

fn new(coefficient: i128, scale: u32) -> Result<Self, DecimalError>
Build coefficient × 10^-scale.
fn parse(text: &str) -> Result<Self, DecimalError>
Read a decimal literal: -?[0-9]+(\.[0-9]+)?([eE][+-]?[0-9]+)?, inf or -inf.
fn is_infinite(self) -> bool
Whether the decimal is one of the infinities.
fn parts(self) -> Option<(i128, u32)>
The coefficient and the scale, or None for an infinity.
fn to_f64(self) -> f64
The nearest binary64, ties to even (spec/data-model.md, *Decimals*).
fn checked_sub(self, other: Self) -> Option<Self>
The exact difference self − other, with the larger of the two scales, or None when it does not fit in 38 digits or an operand is infinite (spec/explain.md, *Counterfactuals*).
