Manual / Chapter 14

Python API

Every name the cleanrules package exports, with its signature and the description from its docstring. The listing is generated from the installed package, so it matches the code this manual ran (commit 29b1ca3). evaluate_tree and evaluate_value_tree, added with the conformance runner (task C.5), are not in that commit yet and are not listed.

Signatures and descriptions are read from the package by introspection (inspect.signature and the docstrings). Operators are listed under Expr. Errors are described in the Errors chapter.

Building conditions#

objectF

The start of every field path: F.customer.age >= 18, F["a key"], F.items[0].

classField(*path: str | int) -> None

A value looked up in the input data by path, e.g. Field("orders", 0, "total").

Arguments

*path
Keys or attribute names (str) and sequence indices (int >= 0), outermost first.

Methods and properties

path (property)
The keys and indices of the path, outermost first.

classConst(value: object) -> None

A constant: None, bool, int, float, Decimal, str, date or datetime.

Arguments

value
The constant.

Methods and properties

value (property)
The constant, as a Python value.

classExpr

A node of a condition tree, immutable.

Operators: == != < <= > >= build comparisons; & | ~ build and, or and not; + - * /, unary - and abs() build arithmetic. Using a node as a Python bool, iterating it or testing in raises ExpressionError. Nodes are built with F, Field, Const, operators and methods, never directly.

Methods and properties

tag (property)
The node's tag, such as "gt" or "and" (spec/ast.md, *Catalogue*).
kind (property)
Whether the node is a condition, a value, or any (depends on the data).
children(self) -> tuple[Expr, ...]
Return the direct child nodes, in order.
walk(self) -> Iterator[Expr]
Yield this node and all its descendants in pre-order (parents first).
field_paths(self) -> tuple[tuple[str | int, ...], ...]
Return the paths of every field this node reads, in first-appearance order.
same_as(self, other: object) -> bool
Return whether other is a node with the same structure and constants.
structural_key(self) -> StructuralKey
Return a hashable key that is equal for nodes that are same_as each other.
is_in(self, values: Iterable[object]) -> Expr
Test membership in a set of constants, e.g. F.country.is_in({"ES", "PT"}).
between(self, low: object, high: object, closed: Closed = 'both') -> Expr
Test a range, e.g. F.age.between(18, 65) or F.x.between(F.lo, F.hi).
is_null(self) -> Expr
Test whether the value is missing or null; never unknown.
matches(self, pattern: str) -> Expr
Search a string with a regular expression, e.g. F.email.matches(r".+@.+").
starts_with(self, text: str) -> Expr
Test that a string starts with the literal text (not a pattern).
ends_with(self, text: str) -> Expr
Test that a string ends with the literal text (not a pattern).
contains(self, text: str) -> Expr
Test that a string contains the literal text.
abs(self) -> Expr
Return the absolute value of a number; the same as abs(node).

classStructuralKey(node: Expr) -> None

A hashable stand-in for a node, equal for nodes that are same_as each other.

type aliasKind

Where a node may appear: "condition", "value", or "any" (depends on the data).

Literal['condition', 'value', 'any']

type aliasClosed

Which ends of between are included: "both", "left", "right" or "none" (the same names as polars).

Literal['both', 'left', 'right', 'none']

Rules and rule sets#

classRule(name: str, when: Expr, then: Mapping[str, object] | None = None, *, priority: int = 0, tags: Iterable[str] = (), description: str | None = None, metadata: Mapping[str, object] | None = None, do: Action | None = None) -> None

A named condition and its payload.

Arguments

name
Unique within a rule set; appears in decisions and errors.
when
The condition; the rule fires when it is true.
then
The payload: string keys whose values are constants or value expressions such as F.total * 0.1. Its order is kept.
priority
Used by the PRIORITY hit policy; higher wins.
tags
Labels for grouping and filtering.
description
A human-readable description.
metadata
Free-form data (owner, ticket, version, ...).
do
An action: a callable that RuleSet.run calls with an ActionContext when the rule is selected (never evaluate).

Methods and properties

when (property)
The condition.
then (property)
The payload, in order; empty when the rule has none.
priority (property)
The priority, for the PRIORITY hit policy.
tags (property)
The tags, in order and without repeats. The core keeps tags sorted, without repeats (see the output in Rules and rule sets).
description (property)
The description, if any.
metadata (property)
The metadata, as the core holds it (read-only).
do (property)
The action, if any.

classRuleSet(rules: Iterable[Rule], *, hit_policy: HitPolicy | str = 'first', aggregate: Aggregate | str | None = None, logic: str = 'boolean', strict: bool = False) -> None

Rules evaluated together under a hit policy.

Arguments

rules
The rules, in order; names must be unique.
hit_policy
How the rules that fired become a decision (HitPolicy or its name).
aggregate
With COLLECT, combine the outputs: "sum", "min", "max" or "count".
logic
The logic, by name; "boolean" is Kleene's three-valued logic.
strict
Raise an EvaluationError instead of returning unknown for missing fields and type mismatches.

Methods and properties

rules (property)
The rules, in order.
hit_policy (property)
The hit policy.
aggregate (property)
The COLLECT aggregate, if any.
logic (property)
The logic's name.
strict (property)
Whether evaluation raises instead of returning unknown.
evaluate(self, data: object) -> Decision
Evaluate the rule set on one input.
run(self, data: object) -> Decision
Evaluate like evaluate, then run the actions of the selected rules.
evaluate_many(self, rows: Iterable[object]) -> list[Decision]
Evaluate the rule set on each input of a batch, in order.
summary(self) -> Summary
Describe the rule set without evaluating it: rules, fields read, outputs, tags.
get(self, name: str, default: Rule | None = None) -> Rule | None
Return the rule with that name, or default.

enumHitPolicy

How a rule set turns the rules that fired into a decision (spec/rules.md).

Members

HitPolicy.FIRST = 'first'
The first rule that fired, in rule order.
HitPolicy.PRIORITY = 'priority'
The rule that fired with the highest priority; ties go to rule order.
HitPolicy.UNIQUE = 'unique'
The only rule that fired; more than one is a HitPolicyError.
HitPolicy.ANY = 'any'
The first rule that fired; the rules that fired must agree on their outputs.
HitPolicy.RULE_ORDER = 'rule_order'
Every rule that fired, in rule order.
HitPolicy.COLLECT = 'collect'
Every rule that fired, in rule order, optionally combined by an aggregate.

Properties

single_hit
Whether at most one rule is selected.

enumAggregate

How COLLECT combines the outputs of the rules that fired.

Members

Aggregate.SUM = 'sum'
The sum of the non-null values (decimals are added as floats).
Aggregate.MIN = 'min'
The smallest non-null value.
Aggregate.MAX = 'max'
The largest non-null value.
Aggregate.COUNT = 'count'
The number of non-null values.

functionAction(*args, **kwargs)

dataclassActionContext

What an action receives (spec/rules.md, *Actions*).

Attributes

rule : Rule
The rule whose action runs.
data : object
The input, as given to RuleSet.run.
result : RuleResult
The rule's result in the decision: its truth and its output.
output : Mapping[str, object]
The rule's evaluated payload (empty when it has none).
decision : Decision
The whole decision.

Decisions#

classDecision

The outcome of evaluating a rule set on one input. Immutable.

Attributes

ruleset
The rule set that decided.
results
Every rule's result, in rule order.
selected
The results the hit policy selected, in rule order.

Methods and properties

hit_policy (property)
The hit policy that decided.
fired (property)
The names of the rules that fired, in rule order (selected or not).
outputs (property)
The payloads of the selected rules, in rule order (read-only).
output (property)
The single output: the winner's payload or the aggregate; None if none.
aggregated (property)
With COLLECT and an aggregate, its values; None when nothing was selected.
explain(self) -> Explanation
Explain every rule: selected, fired but not selected, not fired, or unknown.
why_not(self, name: str) -> RuleExplanation
Explain one rule, typically one that did not fire or was not selected.
to_dict(self) -> dict[str, Any]
The decision document of the JSON format (spec/json-format.md, *Decisions*).

Methods and properties

The causes of the requirement, in order, without their grouping.

enumStatus

What happened to a rule in a decision (spec/explain.md).

Members

Status.SELECTED = 'selected'
The rule fired and the hit policy selected it.
Status.FIRED = 'fired'
The rule fired but was not selected; its note says why.
Status.NOT_FIRED = 'not_fired'
The rule's condition was false.
Status.UNKNOWN = 'unknown'
The rule's condition was unknown: data was missing or of the wrong type.

Errors#

exceptionCleanRulesError

Base class of every error raised by cleanrules.

Code —; bases: Exception.

exceptionFormatError

A document is invalid.

Code format_error; bases: CleanRulesError.

exceptionExpressionError

A condition node breaks a construction rule (expression_error).

Code expression_error; bases: CleanRulesError, TypeError, ValueError.

exceptionRuleDefinitionError

A rule or rule set breaks a construction rule (rule_definition_error).

Code rule_definition_error; bases: CleanRulesError, ValueError.

exceptionRuleSyntaxError

A text in the rule syntax cannot be parsed (rule_syntax_error).

Code rule_syntax_error; bases: CleanRulesError, ValueError.

exceptionRegistryError

A name is not registered (registry_error).

Code registry_error; bases: CleanRulesError, LookupError.

exceptionRuleNotFoundError

A rule set has no rule by that name (rule_not_found).

Code rule_not_found; bases: CleanRulesError, KeyError.

exceptionEvaluationError

Strict evaluation cannot go on (evaluation_error and its children).

Code evaluation_error; bases: CleanRulesError.

exceptionMissingFieldError

Strict mode met a field that cannot be resolved (missing_field).

Code missing_field; bases: EvaluationError.

exceptionTypeMismatchError

Strict mode met values of incompatible types (type_mismatch).

Code type_mismatch; bases: EvaluationError.

exceptionHitPolicyError

The hit policy cannot decide (hit_policy_error).

Code hit_policy_error; bases: EvaluationError.

exceptionActionError

An action raised while running a decision (action_error).

Code action_error; bases: CleanRulesError.

exceptionUnsupportedError

This build, logic or format version cannot do the operation (unsupported).

Code unsupported; bases: CleanRulesError, NotImplementedError.
