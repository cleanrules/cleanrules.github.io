Manual / Chapter 18

Java API

The Java binding: the same engine and the same concepts as every other language (RuleSet, Decision, explain, summary), on the C ABI through the Foreign Function & Memory API of Java 25. Conditions and rules are built in code with static imports and methods, decisions give Java values back, explanations and summaries are objects, and errors are unchecked exceptions. It has no native code of its own: the bindings of cleanrules.h are written in Java.

Not on Maven Central yet. The artifact io.github.cleanrules:cleanrules is not published (tasks G.3 and M.2); build the jar from the repository (installation). Until the native libraries go inside the jar (task G.1c, in review), point the binding at the C library you built with -Dcleanrules.library.path=..., and allow native access with --enable-native-access. This page is written from bindings/jvm and its README at commit a1758c5; its programs ran with the Java source launcher of OpenJDK 27 (the binding targets Java 25). A Scala 3 layer is being written (task G.2) and is not described here.

A first program#

A rule read from the rule syntax with ruleFromText, one built in code, a decision, why a rule did not fire, the explanation and the summary as text, and the rule set written back. Run with java --enable-native-access=ALL-UNNAMED -Dcleanrules.library.path=target/release -cp cleanrules-0.0.0.jar Api.java:

Api.javaJava binding · runs
import static io.github.cleanrules.Conditions.*;
import static io.github.cleanrules.Documents.*;

import io.github.cleanrules.*;
import java.math.BigDecimal;
import java.util.Map;

public class Api {
    public static void main(String[] args) {
        Rule vip = ruleFromText("RULE vip PRIORITY 10 IF customer.years > 5 AND order.total > 1000 THEN discount = 0.15");
        Rule loyal = Rule.named("loyal")
                .when(field("customer", "years").gt(2))
                .then("discount", new BigDecimal("0.05"))
                .priority(5);
        RuleSet rules = RuleSet.builder().add(vip, loyal).hitPolicy(HitPolicy.PRIORITY).build();

        Decision decision = rules.evaluate(Map.of(
                "customer", Map.of("years", 7),
                "order", Map.of("total", 900)));
        System.out.println(decision.fired() + " " + decision.output().orElseThrow());
        System.out.println(decision.whyNot("vip").causes().getFirst().counterfactual().orElseThrow());
        System.out.println(decision.explain());
        System.out.println(rules.summary());
        System.out.print(dumps(rules, Format.TEXT));
    }
}

Building conditions#

A condition is data, a tree of nodes the core evaluates, never a Java lambda. Java has no operator overloading, so fuzzytool's &, | and ~ are the methods and, or and not. The core builds every node and checks it at once: a node that breaks a construction rule of spec/ast.md, a NaN, an integer beyond 64 bits, a decimal beyond 38 digits, a datetime finer than a microsecond or a constant that is not a scalar is an ExpressionException.

A field by its path: keys as Strings, indexes as ints, field("items", 0, "price"). A key is never split at dots: field("customer.age") is one key.
constant(value)
A constant where no node is involved, such as constant(true). Java values next to a node become constants by themselves (ge(18)).

The connectives, the same as the methods.

Actions#

evaluate never calls actions. run checks that every named action is bound (a RegistryException from the core otherwise, before reading anything), evaluates, and calls the actions of the selected rules in rule order, on the calling thread. An action that throws stops the run with an ActionException whose cause is what it threw, with rule(), executed() (the rules whose actions ran) and decision(); an error of the virtual machine (StackOverflowError…) goes on as it is.

Actions.javaJava binding · runs
import static io.github.cleanrules.Conditions.*;

import io.github.cleanrules.*;
import java.util.Map;

public class Actions {
    public static void main(String[] args) {
        RuleSet rules = RuleSet.builder()
                .add(Rule.named("vip").when(field("years").gt(5)).then("discount", 15).action("notify_sales"),
                     Rule.named("audit").when(field("years").gt(0)).action(context -> {
                         throw new IllegalStateException("audit log unavailable");
                     }))
                .hitPolicy(HitPolicy.RULE_ORDER)
                .build();

        // A named action is data: run refuses it until it is bound.
        try {
            rules.run(Map.of("years", 7));
        } catch (RegistryException e) {
            System.out.println(e.code() + ": " + e.getMessage());
        }

        RuleSet bound = rules.bind(Map.of("notify_sales", context ->
                System.out.println("notify_sales: " + context.rule().name() + " " + context.output())));
        try {
            bound.run(Map.of("years", 7));
        } catch (ActionException e) {
            System.out.println(e.code() + " in " + e.rule().orElseThrow() + ", after " + e.executed()
                    + "; cause: " + e.getCause());
        }
    }
}
Output
registry_error: the action "notify_sales" of rule "vip" is not registered
notify_sales: vip {discount=15}
action_error in audit, after [vip]; cause: java.lang.IllegalStateException: audit log unavailable

interfaceAction, class ActionContext

An Action is context -> { ... }. Its ActionContext has rule(), data() (the object run received), result(), output() (the evaluated payload), decision() (the object run returns) and tree(), the ResultTree of the rule's condition.

Explanations and summaries#

The core's explanation and summary as objects; Java reads them, and never computes any part of them itself. Each has its text as toString() and its document as toJson().

classExplanation, RuleExplanation

An Explanation has rules() (a RuleExplanation per rule), selected() and forRule(name). A RuleExplanation has rule(), status() (Status.SELECTED, FIRED, NOT_FIRED, UNKNOWN), requirement() (a sealed Requirement: a Cause or a CauseGroup), causes() without their grouping, note() and achievable(), as Optionals.

classCause, CauseGroup, Counterfactual, Note, Reason

A Cause has node(), truth(), negated(), holds() (whether it went the way the rule needed), values() (Cause.FieldValue: path() and value()), reason() and counterfactual(). A CauseGroup has a GroupKind (ALL or ANY) and its items. A Counterfactual has path(), op(), target() and gap(): a number, a java.time.Period of days between dates, or a java.time.Duration between datetimes. A Note has a NoteKind (LOWER_PRIORITY, SAME_PRIORITY, ANY_AGREES, EARLIER_RULE), winner(), priority() and winnerPriority(). A Reason has code() (missing_field, type_mismatch…), paths(), types() and detail(). The enums give the format's names with jsonName().

classSummary

What a rule set reads and produces, without evaluating it: hitPolicy(), aggregate(), logic(), isStrict(), rules() (RuleSummary: name(), priority(), outputs(), action(), actionName()), fields() (FieldUsage: path(), conditions(), and payloads() as FieldUsage.Payload(rule, key)), outputs() and tags(). Rules whose action is code are marked.

Documents#

import static io.github.cleanrules.Documents.*; Formats are Format.JSON (the default), YAML, TEXT (the rule syntax) and CSV (decision tables); a file's extension (.json, .yaml, .yml, .rules, .csv) gives its format unless one is given. Reading is the core's, strict and bounded: errors have a JSON Pointer or a line and column, and Limits sets the bounds.

staticloads, load(text[, format[, limits]][, actions]), (path[, format, limits][, actions]): DocumentContent

Read a condition, rule, rule set or decision table document, from a String (or UTF-8 bytes) or a Path. DocumentContent is a sealed interface of Expr, Rule, RuleSet and DecisionTable: take it apart with instanceof or a switch. actions binds the named actions of the rules read; without it they stay unbound. A file beyond the size limit of its format is not read (limit_exceeded). Rules read keep the core's own rules, so they write back exactly.

staticdumps, dump(value[, format[, omitActions]]), (value, path[, format, omitActions])

The canonical document of a condition, rule, rule set or table, as a String or to a file. A value node is an ExpressionException; a rule whose action is code without a name is an UnsupportedException unless omitActions. Decisions are written with Decision.toJson() and write(format).

staticruleFromText(text[, action | actions | limits]), (text, limits, actions)

One rule in the rule syntax (fuzzytool's verb); rule_1 without a RULE line. A name the text gives its action (DO notify) is bound to the action, or looked up in actions.

Decision tables and result trees#

Tables.javaJava binding · runs
import static io.github.cleanrules.Conditions.*;
import static io.github.cleanrules.Documents.*;

import io.github.cleanrules.*;
import java.util.Map;

public class Tables {
    public static void main(String[] args) {
        // A decision table from rows: strings are cells as the CSV writes them.
        DecisionTable table = DecisionTable.builder()
                .hitPolicy(TablePolicy.PRIORITY)
                .header("RULE", field("customer", "years"), "order.total", TableOutput.of("risk", "high", "low"))
                .row("new", field("customer", "years").lt(1), "> 1000", "'high'")
                .row("vip", "> 5", "-", "'low'")
                .row("default", null, null, "'low'")
                .build();
        System.out.print(dumps(table, Format.CSV));
        Decision decision = table.evaluate(Map.of("customer", Map.of("years", 0), "order", Map.of("total", 4000)));
        System.out.println(decision.output().orElseThrow());

        // A document read back: a sealed interface, taken apart with a switch.
        String yaml = dumps(RuleSet.of(ruleFromText("RULE vip IF customer.years > 5 THEN discount = 0.15 DO notify")),
                Format.YAML);
        switch (loads(yaml, Format.YAML, Map.of("notify", context -> System.out.println("notify " + context.output())))) {
            case RuleSet rules -> rules.run(Map.of("customer", Map.of("years", 7)));
            default -> throw new IllegalStateException("not a rule set");
        }

        // One condition on its own, with the result of every node.
        Expr vip = field("customer", "years").gt(5).and(field("order", "total").gt(1000));
        ResultTree tree = vip.evaluateTree(Map.of("customer", Map.of("years", 7)));
        for (ResultTree child : tree.children()) {
            System.out.println(child.node() + ": " + child.truth().orElseThrow().jsonName()
                    + child.reason().map(r -> " (" + r.code() + ")").orElse(""));
        }
    }
}

A decision table and the rule set it compiles into, built with DecisionTable.of(header, rows) or DecisionTable.builder() (header(...), row(...), rows(...), hitPolicy(TablePolicy), aggregate, logic, strict, limits), or read from CSV. Java data is read along the rule set's field paths only, each object once (spec/data-model.md, Java and Scala):

Nothing but public data is read: no private member, no method with parameters, no static member, and nothing a class of the platform declares (getClass()), so a rule loaded from a file cannot reach a Class, a ClassLoader or a Thread. A getter that throws gives a null with reason read_error (in strict mode, an EvaluationException with the exception as its cause). Values come back as null, Boolean, Long, Double, BigDecimal (with its scale), String, LocalDate, LocalDateTime, ZonedDateTime, unmodifiable Lists and SequencedMaps in the engine's order, and, for an opaque value, the very object that was read.

The native layer#

io.github.cleanrules.ffi is what the idiomatic API is built on, and stays available: rule sets read from documents, evaluated on Java data or JSON, with outputs as Java values or JSON text and explanations as text or documents. Its four classes own native memory: close them with try-with-resources, or a Cleaner frees them.

NativeLayer.javaJava binding · runs
import io.github.cleanrules.Format;
import io.github.cleanrules.ffi.Decision;
import io.github.cleanrules.ffi.RuleSet;
import java.math.BigDecimal;
import java.util.Map;

public class NativeLayer {
    record Customer(int years, boolean newsletter) {}

    public static void main(String[] args) {
        try (RuleSet rules = RuleSet.read("""
                HIT POLICY priority
                RULE vip PRIORITY 10
                IF customer.years > 5 AND order.total > 1000
                THEN discount = 0.15
                DO notify_sales
                """, Format.TEXT)) {
            var order = Map.of("customer", new Customer(7, false), "order", Map.of("total", new BigDecimal("1500.00")));
            try (Decision decision = rules.evaluate(order)) {
                Object discount = ((Map<?, ?>) decision.output()).get("discount");
                System.out.println(discount + " " + discount.getClass().getSimpleName());
                System.out.println(decision.outputJson());
            }
            rules.run(order, Map.of("notify_sales", call ->
                    System.out.println("notify " + call.ruleName() + ": " + call.output()))).close();
        }
    }
}

Memory and threads#

Expressions, rules, rule sets, decisions, decision tables and result trees of the idiomatic API are immutable and may be shared between threads: one rule set may evaluate on many threads at once. A Cleaner frees their native memory once they are unreachable, so they have no close(), except decisions, which may be closed early. In the native layer, Document, RuleSet, Decision and Node are AutoCloseable: closing twice does nothing, using a closed object is an IllegalStateException ("this RuleSet is closed"), and closing one while another thread uses it is safe: it is freed when the last call returns. The memory of each call lives in a confined arena freed when the call returns. Actions run on the thread that called run, and may run rule sets again; nothing an action throws crosses the native frames.

Pitfalls#

  • Native access needs a flag. Run with --enable-native-access=ALL-UNNAMED on the class path or --enable-native-access=io.github.cleanrules on the module path. Without it Java prints a warning; with --illegal-native-access=deny, every use of the binding throws an UnsatisfiedLinkError that says which flag to add. A library that cannot be found or loaded, or of another ABI or format version, is an UnsatisfiedLinkError too, every time it is used; CleanRules.load() loads it at once.
  • equals is structural identity, not a comparison: expr.equals(other) never builds a node; eq(other) does. Constants compare by type and value, so ge(18) and ge(18.0) differ, and Exprs work as keys of a HashMap. hashCode() is the core's, stable on every platform for one version of the library: never store it.
  • field never splits at dots. field("customer.age") is one key with a dot in it; write field("customer", "age").
  • Map.of has no order. then(map) keeps the order of a SequencedMap and sorts any other map, so a payload given with Map.of comes out sorted by key; use a LinkedHashMap, or then(key, value) step by step, to choose it.
  • get(name) is an Optional, rule(name) throws a RuleNotFoundException that lists the rules. The same holds for output(), an Optional that is empty when nothing was selected and throws a HitPolicyException under rule_order: use outputs() there.
  • A Decision is AutoCloseable. Closing it frees its native memory early; what was already read stays readable, and what still needs the native decision throws IllegalStateException. Without close(), the Cleaner frees it.
  • ruleFromText(text, null) does not compile: a bare null matches the Action, Map and Limits overloads. Call ruleFromText(text), or ruleFromText(text, limits, actions), where both may be null.
Pitfalls.javaJava binding · runs
import static io.github.cleanrules.Conditions.*;

import io.github.cleanrules.*;
import java.util.LinkedHashMap;
import java.util.Map;

public class Pitfalls {
    public static void main(String[] args) {
        // 1. equals is structural identity, not a comparison node: use eq() for that.
        Expr adult = field("age").ge(18);
        System.out.println(adult.equals(field("age").ge(18)) + " " + adult.equals(field("age").ge(18.0))
                + " | " + field("age").eq(18));

        // 2. field() never splits at dots: "customer.age" is one key.
        System.out.println(field("customer.age").fieldPaths() + " " + field("customer", "age").fieldPaths());

        // 3. then(map) keeps the order of a SequencedMap only; Map.of has none, so it is sorted.
        Rule sorted = Rule.named("r").when(adult).then(Map.of("tier", "gold", "discount", 10));
        var ordered = new LinkedHashMap<String, Object>();
        ordered.put("tier", "gold");
        ordered.put("discount", 10);
        Rule kept = Rule.named("r").when(adult).then(ordered);
        System.out.println(sorted.then().keySet() + " " + kept.then().keySet());

        // 4. get(name) is an Optional; rule(name) throws, listing the rules there are.
        RuleSet rules = RuleSet.of(Rule.named("adult").when(adult));
        System.out.println(rules.get("minor"));
        try {
            rules.rule("minor");
        } catch (RuleNotFoundException e) {
            System.out.println(e.code() + ": " + e.getMessage() + " " + e.available());
        }

        // 5. A decision is AutoCloseable: what was read stays, the rest needs it open.
        Decision decision = rules.evaluate(Map.of("age", 20));
        System.out.println(decision.fired());
        decision.close();
        System.out.println(decision.fired());
        try {
            decision.explain();
        } catch (IllegalStateException e) {
            System.out.println(e.getMessage());
        }
    }
}

CleanRules and Limits#

classCleanRules

FORMAT_VERSION (1), the version of the JSON format, and ABI_VERSION, of the C ABI this binding was written for; loading compares both with the library's. version() is the library's version (0.0.0 until the first release), load() loads it now, and libraryPath() says where it came from. The library is looked up in the system property cleanrules.library.path or the environment variable CLEANRULES_LIBRARY_PATH (its file, or the directory that holds it), then java.library.path, then the system's loader. The binding needs a 64-bit platform.

classLimits

Immutable bounds on what is read: Limits.defaults(), read from the core, and withMaxSize(n) (JSON, YAML and text), withMaxNesting, withMaxDepth, withMaxTableSize, withMaxYamlSize, withMaxTextSize, each a new Limits. They apply to documents, to Java data (its nesting) and to files.
